# ~/oitrika — portfolio

Built for the Kshitij Web Development and AI Workshop 2026, IIT Kharagpur.

## About
A personal portfolio website made entirely with HTML and CSS — no JavaScript.
The design is dark and minimal with a space-inspired aesthetic. Light mode switches to a soft pink
theme because why not.

## Features
- Sticky navbar with smooth scroll
- Hero section with animated gradient text
- Projects gallery with CSS Grid
- Contact form with custom focus states
- Footer with social links
- Fully responsive on mobile
- CSS-only dark/light mode toggle (no JS, just :has and a hidden checkbox)

## Built with
- HTML5
- CSS3
- Google Fonts — Cardo, Cormorant Garamond, DM Sans
